# [BRAND NAME] — homepage

Static homepage for a Colorado western fine art photography print shop.
Open `index.html` in a browser, or serve it with GitHub Pages.

## Replace before launch
- `[BRAND NAME]`, `[TOWN]`, `[YOUR PRICE]`, `[Print title]`, `[Edition title]`, `[X] of [25]`
- Story and horse placeholders in the "Our story" section
- Every image in `images/` with her own photos (keep the file names, or update the `src` paths)
- Link targets (`#product`, `#etsy`, etc.) once the shop exists
- The email form `action` (point it at the email service she picks)
